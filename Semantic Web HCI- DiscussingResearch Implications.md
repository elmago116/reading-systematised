Abstract
Semantic Web progress is very active –and this past
year shows a much greater focus on the subject of user
interaction. W3C leaders talk about the importance and
“grand challenges”for user interaction. Workshops
showcase more well-developed projects and innovative
interaction designs. A W3C mailing list has begun. But
what are the implications for the HCI community? What
research and practice contributions can be made, and
what relationships can be fostered with the semantic
web research community? This collaborative,
interactive session will give CHI participants a chance
to discuss the issues that have surfaced at recent
semantic web workshops.

What is the “Semantic” Web?
The semantic web has been defined as "…an extension
of the current web in which information is given well-
defined meaning, better enabling computers and people
to work in cooperation." [7]
1 Semantic Web User Interaction list: public-semweb-ui@w3.org.
One goal of the semantic web is to allow the web to be
more “machine readable” through semantic markup
that is embedded in web data. “Meaning” is derived
from corresponding ontologies that describe and define
data and the relationships between data, based on
internationally agreed formats. Rules and logic allow
that data to be subject to inferencing to further extend
the meaning represented by the creator of the data.
This, in turn, allows machines to consume semantic
data and take actions based on it, without relying solely
on human interpretation of the information. The result
may be more contextually relevant information and
applications that help users accomplish their goals
more easily.
The semantic web can potentially help us overcome
some of the challenges and limitations we currently
face when designing to meet user needs, by providing:
 Greater user context available to make
application/site behavior more user-centered
 More flexible and adaptive language parsing and
“understanding” to make the conversation with the
computer more effective
 Better visualizations and representations of
complex data and interactions
 Agents that can manage routine background tasks
and reduce the need for users to hunt and search
among thousands, millions, or billions of items of
information without adequate support
 Sharable ontologies and vocabularies, allowing all
the applications and sites that a user sees to speak a
“similar language” and reducing the demand on the
user to interpret language when trying to complete a

us to consider where and how “semantic enabling” user

What “Grand Challenges”Exist Now?
There are a range of design considerations and
challenges that are being elicited from prior workshops
and the SWUI mailing list. A preliminary list of these
challenges was posted on the SWUI workshop site for
discussion in November 2006 [12].
Discussion Topics
There are a number of areas that need to be
considered, which present opportunities for
contributions from current and future research.
The HCI community needs a forum to provide feedback
and ideas on subjects such as:
 Visualization and maintainability of data sets,
ontologies, relationships, rules, and even permissions
that are needed to “drive” the semantic web
 Contextualizing searching and querying, including
the role of user context, preferences, agents, and
ontology in advanced searches
 Browsing across multiple data sets, particularly
where the data sets may be new or dynamic via the
web (“open world scenario”) rather than designed or
modeled in advance (e.g. [6, 8, 10, 13])
 Simple data entry –capturing semantically-rich
metadata without creating undue burden on
users/authors (because otherwise the tagging won’t
happen)
 Identifying useful methods for user-centered
analysis and design of semantic applications, and gaps
in available methods that will require new methods to
be developed
 Using semantic technologies to help overcome HCI
research/design problems, such as integrating design
patterns from multiple reference sites (e.g. [11])
 Authorizing, managing and empowering agents
 Addressing privacy concerns, informed consent,
and trust issues
Outcomes and insights from CHI will be posted to the
SWUI mailing list and web site2, where they can be
refined in collaboration with semantic web researchers.
